# Experiencia Ibérica

Sitio web de Experiencia Ibérica: cocina española en vivo a domicilio en Torreón, Coahuila.

- `index.html`: el sitio completo, con el cotizador y el calendario de disponibilidad.
- `data.json`: menú, precios y fechas ocupadas. Se actualiza automáticamente dos veces al día desde la app de gestión.
- `img/`: fotos y logo.
